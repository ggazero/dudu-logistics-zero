[이 화면은]
단계가 없습니다. 한 화면에 전부 있고, 값을 넣는 즉시 옆에서 계산 과정이 펼쳐집니다.
왜 이 요금이 나왔는지 눈으로 따라갈 수 있습니다.

[오늘 할 일]
1. 화면을 열고 처음부터 끝까지 한 번 접수해 봅니다.
2. 어제 내가 쓴 정책서를 펼칩니다.
3. 정책서에 적은 규칙이 이 화면에서 실제로 도는지 하나씩 확인합니다.
4. 안 되는 것을 하나 골라 고칩니다.
