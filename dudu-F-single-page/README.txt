[중요]
현재 GitHub·Vercel 배포 소스는 프로젝트 루트의 아래 파일입니다.

- ../index.html
- ../js/
- ../assets/
- ../api/

이 폴더 안의 파일은 비교·참고용이며 Vercel 운영 화면 수정에 사용하지 않습니다.

- single-page.html: 최초 한 장 완성판 보관본
- index.html: 정책 화면 초기 프로토타입
- js/, assets/: 초기 프로토타입 전용 소스

현재 화면을 수정할 때는 루트 소스만 수정하세요.
